# Student Record Management System (C Mini Project)

A simple menu-driven C program to manage student records.

**Submitted by:** Kunal Chaudhary (UID 26BCD10241)
**Submitted to:** Ms. Khushi Aggarwal, Assistant Professor
**University:** Chandigarh University

## Features
1. Add student (rejects duplicate roll numbers)
2. Display all students (total, percentage, grade)
3. Search student by roll number
4. Update student marks
5. Delete student
6. Show topper

## Concepts used
Structures, arrays, functions, pointers, loops, if-else, switch-case, do-while.

## Compile and run
```
gcc -std=c99 -Wall -Wextra -o student_record student_record.c
./student_record
```
